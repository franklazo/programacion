# ¿Qué es Python?

- Lenguaje **de propósito general**: sirve para casi cualquier tipo de proyecto.
- **Interpretado:** un programa llamado *intérprete* lee tu código y lo ejecuta línea a línea, sin pasos previos complicados. Puedes escribir y probar al instante.
- **Legible:** su sintaxis se parece bastante al inglés y obliga a escribir el código ordenado (con sangrías).
- **Gratuito y de código abierto**, con una comunidad enorme y mucha documentación.
- **"Baterías incluidas":** trae de serie muchas herramientas útiles (fechas, archivos, matemáticas...).
