# Qué es un lenguaje de programación 🔠

- Es un idioma con reglas estrictas (la **sintaxis**) para dar instrucciones a un ordenador.
- Los ordenadores solo entienden código binario (ceros y unos). Los lenguajes permiten escribir de forma legible para humanos, y algo traduce eso a lo que la máquina entiende.
- **Código fuente:** el texto que tú escribes (por ejemplo, un archivo `.py`).
- **Programa en ejecución:** lo que el ordenador hace cuando "corre" ese código.
- Hay muchos lenguajes (Python, JavaScript, C, Java...). Los conceptos básicos son muy parecidos entre ellos, así que lo que aprendas te servirá más allá de Python.
