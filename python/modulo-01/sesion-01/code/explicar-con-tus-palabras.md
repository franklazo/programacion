# Ejercicio 4

- **Código fuente vs. programa en ejecución**: el código fuente es el texto que escribes (el archivo `.py`); el programa en ejecución es lo que el ordenador hace cuando lee y ejecuta ese código.
- **Python es interpretado**: un programa llamado intérprete lee tu código y lo ejecuta línea a línea, así que puedes escribir y probar al instante, sin pasos previos complicados.
- **El ordenador no adivina**: solo sigue instrucciones literales. No interpreta intenciones ni rellena huecos, así que si falta un paso o está mal, el programa falla o hace algo distinto de lo que querías.
