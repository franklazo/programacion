# Tu objetivo personal

Es una respuesta personal, así que no hay una solución única. Un buen ejemplo tiene este formato:

> "Quiero construir un programa que [*qué hace*] para resolver [*qué problema*]."

Ejemplos válidos:

- "Un programa que organice automáticamente mi carpeta de descargas, para no tener que ordenarla a mano."
- "Una app que lleve el control de mis gastos mensuales, para saber en qué gasto más."
- "Un script que renombre en bloque las fotos de mis viajes, para tenerlas ordenadas por fecha."
