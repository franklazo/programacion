# Comandos básicos de navegación

| Qué hace                 | Windows         | macOS / Linux |
| :---                     | :---            | :---          |
| Ver en qué carpeta estás | `cd` (sin nada) | `pwd`         |
| Listar contenido         | `dir`           | `ls`          |
| Entrar en una carpeta    | `cd nombre`     | `cd nombre`   |
| Subir un nivel           | `cd ..`         | `cd ..`       |
| Limpiar la pantalla      | `cls`           | `clear`       |

**Trucos útiles:**

- `Tab` autocompleta nombres de archivos y carpetas.
- La flecha ↑ recupera el comando anterior.
- Si el nombre tiene espacios, ponlo entre comillas: `cd "mi carpeta"`.
