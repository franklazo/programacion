# Ejecutar un archivo con `python archivo.py`

- Navega hasta la carpeta donde está tu archivo:

```shell
cd python-curso/modulo-01
```

- Comprueba que está ahí (`dir` o `ls`).
- Ejecútalo:

```shell
python hola.py
```

- En macOS y Linux puede ser `python3 hola.py`.

**Errores frecuentes:**

- `can't open file ...`: no estás en la carpeta correcta, o el nombre está mal escrito.
- `python no se reconoce...` (Windows): Python no se añadió al PATH durante la instalación.
