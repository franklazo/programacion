# Varias instrucciones y orden de ejecución

Python lee el código **de arriba abajo, una línea a la vez**.

```python
print("Primero")
print("Segundo")
print("Tercero")
```

Salida:

```text
Primero
Segundo
Tercero
```

- Cada `print()` escribe en una línea nueva.
- Si cambias el orden de las líneas, cambia el orden de la salida.
- Puedes dejar líneas en blanco para separar bloques y que el código se lea mejor.
- Las líneas deben empezar sin espacios al inicio (la sangría tiene un significado especial en Python, y la verás más adelante).
