# Texto entre comillas

Un texto se llama **cadena** (*string*) y siempre va entre comillas, simples o dobles. Ambas funcionan igual:

```python
print("Hola")
print('Hola')
```

Truco útil: si el texto contiene comillas, usa el otro tipo por fuera.

```python
print("Es la casa de 'Ana'")
print('Ella dijo "hola"')
```

Las comillas deben abrirse y cerrarse con el mismo tipo.
