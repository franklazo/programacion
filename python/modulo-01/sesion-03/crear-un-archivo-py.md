# Crear un archivo `.py`

- Un programa de Python es un archivo de texto con extensión `.py`.
- En tu editor: **Archivo → Nuevo**, y guárdalo como `hola.py` dentro de `modulo-01`.
- Usa nombres en minúsculas, sin espacios ni acentos (`mi_programa.py`, no `Mi Programa.py`).
- Evita llamar a tus archivos como módulos de Python (`random.py`, `math.py`), porque causan conflictos más adelante.
