## Práctica

- **Programa 1.** Archivo [`hola.py`](code/hola.py):

```python
print("Hola, mundo")
```

- **Programa 2.** Archivo [`presentacion.py`](code/presentacion.py): imprime tu nombre y una frase sobre por qué quieres aprender Python.
- **Programa 3.** Archivo [`dibujo.py`](code/dibujo.py): crea un dibujo con texto y comenta cada parte. Ejemplo:

```python
# Techo
print("  /\\  ")
print(" /  \\ ")
# Paredes
print("|    |")
print("|____|")
```

*(La barra invertida `\` se escribe doble, `\\`, para que aparezca una sola.)*

## Comprobación

- Creas y guardas un `.py` sin ayuda.
- Sabes por qué la salida aparece en ese orden.
- Entiendes para qué sirven las comillas y los comentarios.
- Si algo falla, lees el mensaje de error y buscas la línea indicada.
