# La función `print()`

`print()` muestra información en pantalla. Es tu herramienta principal para ver qué hace tu programa.

```python
print("Hola, mundo")
```

- `print` es el nombre de la función.
- Los paréntesis `()` indican que la estás usando.
- Lo que va dentro es lo que se muestra.
- Python distingue mayúsculas: `Print` o `PRINT` dan error.
