# Comentarios con `#`

Todo lo que sigue a `#` lo ignora Python. Sirve para explicar tu código.

```python
# Esto es un comentario
print("Hola")  # También puede ir al final de una línea
```

**Cuándo usarlos:**

- Para explicar el *por qué* de algo no evidente.
- Para dividir un programa en bloques.
- Para desactivar temporalmente una línea sin borrarla.

**Cuándo no:** no repitas lo que ya dice el código (`# imprime hola` junto a `print("Hola")` no aporta nada).
