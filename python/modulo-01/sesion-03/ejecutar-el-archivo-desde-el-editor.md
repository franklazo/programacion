# Ejecutar el archivo desde el editor

- **Thonny:** botón verde de *Run* (o `F5`).
- **VS Code:** botón ▶ en la esquina superior derecha (o clic derecho → *Run Python File in Terminal*).
- El resultado aparece en la **consola** o **terminal** del editor.
- Si cambias el código, **guarda** (`Ctrl+S`) y vuelve a ejecutar.
