# Buscar el error en internet

- Copia la **última línea** del error, sin nombres de archivo ni rutas tuyas.
- Búscala tal cual, añadiendo `python`. Ejemplo: `python NameError name is not defined`
- Mejores fuentes: documentación oficial de Python y Stack Overflow.
- Busca en inglés si no encuentras nada en español: hay muchos más resultados.
