## ✏ Práctica

1. Crea `python-curso/modulo-01/`.
2. Ábrela en tu editor.
3. Crea un archivo [`prueba.py`](code/prueba.py) con esta línea y ejecútalo:

```python
print("Entorno listo")
```

## ✔ Comprobación

- [ ] `python --version` (o `python3 --version`) muestra un número de versión.
- [ ] Tu editor abre la carpeta y ejecuta `prueba.py` mostrando **Entorno listo**.
