# Práctica 2

- **Verificar la versión de Python.** Ejecuta `python --version` (o `python3 --version`) en la terminal y anota el resultado.
- **Crear tu estructura de carpetas.** Crea `python-curso/modulo-01/` y ábrela en tu editor.
- **Ejecutar tu primer archivo.** Crea [`prueba.py`](code/prueba.py) con `print("Entorno listo")`, guárdalo y ejecútalo desde el editor.
- **Ejecutar desde la terminal.** Con la terminal abierta dentro de `modulo-01`, ejecuta `python prueba.py` (o `python3 prueba.py`) y comprueba que obtienes el mismo resultado.
