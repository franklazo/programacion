# Elegir un editor

|            | **Thonny**                       | **VS Code**                      |
| :---       | :---                             | :---                             |
| Dificultad | Muy fácil                        | Media                            |
| Ventaja    | Todo en uno, sin configurar nada | Potente y útil para toda la vida |
| Ideal para | Primeras semanas                 | Cuando ya te sientas cómodo      |

- **Recomendación:** empieza con Thonny y pasa a VS Code más adelante (o empieza directamente con VS Code).
- **Thonny:** descárgalo de [thonny.org](https://thonny.org/). Incluye su propio Python.
- **VS Code:** descárgalo de [code.visualstudio.com](https://code.visualstudio.com/) e instala la extensión [Python](https://marketplace.visualstudio.com/items?itemName=ms-python.python) (de Microsoft) desde el panel de extensiones.
