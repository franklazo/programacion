# Verificar la instalación ✔

- Abre una terminal:
  - **Windows:** busca *Símbolo del sistema* o *PowerShell*.
  - **macOS/Linux:** abre *Terminal*.
- Escribe:

  ```shell
  python --version
  ```

  En macOS/Linux, si no responde, prueba `python3 --version`.
- Debería mostrar algo como `Python 3.x.x`.
- **Si da error en Windows:** vuelve a ejecutar el instalador, elige *Modify* y activa PATH, o reinstala marcando la casilla.
