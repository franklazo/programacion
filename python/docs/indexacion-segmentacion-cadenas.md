# Indexación/segmentación

```python
# Indexación:
"Python"[0]   # primer caracter  = 'P'
"Python"[2]   # tercer caracter  = 't'
"Python"[5]   # último caracter  = 'n'

"Python"[-6]  # primer caracter  = 'P'
"Python"[-4]  # tercer caracter  = 't'
"Python"[-1]  # último caracter  = 'n'
```

```python
# Segmentación:
"Python"[2:5]    # inicio:fin       = 'tho'
"Python"[2:5:2]  # inicio:fin:paso  = 'to'
```
