# ¿Para qué sirve programar?

La programación permite crear soluciones informáticas para diferentes necesidades.

Sus aplicaciones incluyen:

| Área           | Ejemplo                         |
| :------------- | :------------------------------ |
| Cálculos       | Calculadoras y conversores      |
| Gestión        | Inventarios y agendas           |
| Automatización | Organización de archivos        |
| Información    | Procesamiento de datos          |
| Aplicaciones   | Programas de escritorio         |
| Comunicación   | Conexión con servicios externos |

La utilidad de programar está en poder transformar una necesidad en una solución que pueda ejecutar un ordenador.
