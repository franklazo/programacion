# Salida estándar

```python
print()  # línea vacía
```

```python
print("Python")           # final con salto de línea
print("Python", end=" ")  # final con espacio
```

```python
print("A", "B", "C")           # separador por defecto    = A B C
print("A", "B", "C", sep="-")  # separador personalizado  = A-B-C
```
