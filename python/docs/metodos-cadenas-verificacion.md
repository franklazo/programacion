# Métodos de verificación

```python
"123".isdigit()        # 0-9 y no vacío
"Ana".isalpha()        # a-z, A-Z y no vacío
"x1A".isalnum()        # a-z, A-Z, 0-9 y no vacío
" \n".isspace()        # espacios, tabulaciones o nuevas líneas

"ABC".isupper()        # mayúsculas y no vacío
"abc".islower()        # minúsculas y no vacío

"xyz".startswith("x")  # caracteres de inicio
"xyz".endswith("z")    # caracteres de final
```
