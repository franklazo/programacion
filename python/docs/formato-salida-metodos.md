# Formato de salida (métodos)

```python
# Alinear y rellenar
"Ana".ljust(7, "-")   # izquierda  = Ana----
"Ana".center(7, "-")  # centro     = --Ana--
"Ana".rjust(7, "-")   # derecha    = ----Ana
```

```python
# Valores, variables o expresiones entre {}
"Hola {}, tienes {} años.".format("Ana", 25)  # Hola Ana, tienes 25 años.
```
