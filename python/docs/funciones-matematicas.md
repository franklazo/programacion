# Funciones matemáticas

```python
abs(-7)        # valor absoluto    = 7
divmod(10, 3)  # cociente y resto  = (3, 1)

# Redondear al par más cercano (redondeo bancario)
round(2.5)         # 2
round(3.5)         # 4
round(3.14159, 2)  # 3.14
```

```python
float("inf")   # infinito positivo
float("-inf")  # infinito negativo
```
