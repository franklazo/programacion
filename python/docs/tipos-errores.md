# Tipos de errores

| Tipo                | Significado                                  |
| :---                | :---                                         |
| `SyntaxError`       | Sintaxis (paréntesis, comillas, etc.)        |
| `NameError`         | Nombre no definido (variable, función, etc.) |
| `TypeError`         | Tipos de operandos no compatibles            |
| `ValueError`        | Literal o valor no válido                    |
| `ZeroDivisionError` | División entre cero                          |
