# ¿Qué tipos de problemas se pueden resolver mediante programación?

Principalmente, aquellos que pueden describirse mediante pasos, reglas y operaciones que un ordenador pueda ejecutar.

Ejemplos:

- Calcular el importe total de una compra.
- Clasificar archivos según su extensión.
- Buscar información dentro de una lista.
- Registrar y consultar gastos.
- Convertir cantidades entre distintas unidades.
- Generar informes automáticamente.

Un problema debe poder expresarse de manera suficientemente clara para que sus instrucciones puedan ser ejecutadas.
