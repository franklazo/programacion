# Asignación

```python
n = 10   # simple                = 10
n += 20  # con suma              = 30
n -= 15  # con resta             = 15
n *= 3   # con multiplicación    = 45
n /= 2   # con división decimal  = 22.5
n //= 2  # con división entera   = 11.0
n %= 6   # con módulo            = 5.0
n **= 2  # con potencia          = 25.0
```
