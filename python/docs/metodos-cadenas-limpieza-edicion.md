# Métodos de limpieza y edición

```python
# Eliminar espacios:
" Cad ".strip()   # izquierda y derecha  = 'Cad'
" Cad ".lstrip()  # izquierda            = 'Cad '
" Cad ".rstrip()  # derecha              = ' Cad'
```

```python
"ANA".replace("A", "E")  # reemplazar cadenas                = 'ENE'
"A B".split(" ")         # cadenas usando un delimitador     = ['A', 'B']
"-".join("ABC")          # concatenar cadenas con separador  = 'A-B-C'
```
