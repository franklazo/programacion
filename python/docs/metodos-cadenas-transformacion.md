# Métodos de transformación

```python
c = "hOlA aNa"

c.lower()       # minúsculas                                 = 'hola ana'
c.upper()       # mayúsculas                                 = 'HOLA ANA'
c.title()       # primera letra de cada palabra a mayúscula  = 'Hola Ana'
c.capitalize()  # primera letra a mayúscula                  = 'Hola ana'
c.swapcase()    # cada carácter a case contrario             = 'HoLa AnA'
```
