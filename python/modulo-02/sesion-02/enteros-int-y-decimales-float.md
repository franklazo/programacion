# Enteros (`int`) y decimales (`float`)

- **`int`**: números sin parte decimal, positivos o negativos. Sin límite de tamaño práctico.
- **`float`**: números con punto decimal (se escribe con **punto**, no coma).

```python
edad = 25            # int
precio = 19.99       # float
temperatura = -3     # int negativo
grande = 1_000_000   # el guion bajo mejora la lectura
cientifico = 2.5e3   # 2500.0
```

**Ojo:** `5` es `int`, pero `5.0` es `float`.
