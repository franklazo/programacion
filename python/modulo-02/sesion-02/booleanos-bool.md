# Booleanos (`bool`)

- Solo dos valores: `True` y `False` (con mayúscula inicial).
- Surgen de comparaciones y se usan para tomar decisiones.

```python
es_mayor = 18 >= 18      # True
tiene_permiso = False
print(type(es_mayor))    # <class 'bool'>
```

Internamente, `True` vale 1 y `False` vale 0 (`True + True` da `2`).
