# Errores comunes

| Error                  | Causa                               | Ejemplo                           |
| :---                   | :---                                | :---                              |
| `NameError`            | Usar una variable que no existe aún | `print(total)` sin haberla creado |
| `SyntaxError`          | Nombre inválido                     | `2nombre = "Ana"`                 |
| Confundir `=` con `==` | `=` asigna y `==` compara           | `if x = 5` ❌                     |
| Error de mayúsculas    | `Nombre` ≠ `nombre`                 | Crear `nombre` y usar `Nombre`    |
