# Temario completo de Python

**Objetivo general:** aprender programación desde cero utilizando Python como lenguaje principal, adquiriendo los conocimientos necesarios para diseñar, desarrollar, ejecutar y mantener aplicaciones y herramientas propias.

La idea no es prepararte para trabajar en un equipo de desarrollo, convertirte en especialista en una rama concreta ni acumular conocimientos de frameworks. El objetivo es que puedas enfrentarte a un problema, pensar cómo resolverlo y construir una solución funcional por tu cuenta.

| ----------- | ------------------------------------ |
| Python      | Lenguaje principal                   |
| VS Code     | Escribir y ejecutar código           |
| Terminal    | Ejecutar y gestionar programas       |
| pip         | Instalar bibliotecas                 |
| venv        | Crear entornos independientes        |
| Git         | Controlar versiones                  |
| Tkinter     | Crear interfaces gráficas            |
| SQLite      | Almacenar información                |
| SQL         | Consultar y gestionar bases de datos |
| Requests    | Consumir APIs                        |
| JSON / CSV  | Intercambiar y almacenar datos       |
| PyInstaller | Crear ejecutables                    |

Tecnologías que dejaría fuera inicialmente:

- Django y Flask.
- Desarrollo avanzado de backend.
- Frameworks de frontend.
- Machine Learning.
- Ciencia de datos.
- Inteligencia artificial especializada.
- DevOps y despliegue empresarial.
- Arquitecturas de microservicios.
- Programación distribuida.

No porque carezcan de utilidad, sino porque no son necesarias para alcanzar el objetivo planteado.

### Reglas que seguiría durante la formación

1. No avanzar sin comprender los conceptos anteriores.
2. Escribir el código personalmente, no limitarse a copiarlo.
3. Resolver ejercicios sin consultar inmediatamente las soluciones.
4. Aprender a leer e interpretar los errores.
5. Construir pequeños programas desde los primeros módulos.
6. Volver a utilizar conceptos anteriores en proyectos nuevos.
7. Aprender a consultar la documentación oficial.
8. Priorizar comprender cómo resolver problemas antes que memorizar código.

### 7. Mi recomendación sobre el enfoque del temario

Hay una decisión pedagógica importante: **no conviene confundir aprender Python con aprender a desarrollar aplicaciones.**

Son dos niveles relacionados, pero diferentes:

- Primero debes aprender a programar: variables, condiciones, bucles, funciones, estructuras de datos y objetos.
- Después debes aprender a construir soluciones: archivos, bases de datos, interfaces, APIs, automatización y distribución.
- Finalmente debes aprender a combinar todo lo anterior para desarrollar herramientas que resuelvan problemas reales.

Por eso, este temario prioriza los fundamentos y la capacidad de construir soluciones independientes, en lugar de centrarse en tecnologías de moda o especializaciones profesionales.

**El objetivo final no es que sepas utilizar un framework concreto, sino que puedas imaginar una herramienta, diseñar cómo debería funcionar, programarla, detectar sus errores y conseguir que funcione como una aplicación real.**

Con este enfoque tendrás una base de programación general suficientemente sólida para explorar después cualquier otra tecnología sin tener que volver a empezar desde cero.
