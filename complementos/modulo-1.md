# **Módulo 1. Introducción a la programación y Python**

## **Tema 1. Fundamentos de programación**

Conceptual

Primera sesión de estudio

**Objetivo:** comprender qué es programar y cómo funciona un programa informático.

**Contenidos:**

1.1. Introducción a la programación.

- Qué es la programación.
- Qué es un lenguaje de programación.
- Para qué sirve programar.
- Qué tipos de problemas se pueden resolver mediante programación.

1.2. Funcionamiento de los programas.

- Qué es un programa.
- Qué son las instrucciones.
- Qué es el código fuente.
- Qué significa ejecutar un programa.
- Cómo se ejecuta un programa en un ordenador.

1.3. Algoritmos.

- Qué es un algoritmo.
- Características de un algoritmo.
- Secuencia de instrucciones.
- Resolución de problemas mediante algoritmos.
- Relación entre algoritmos y programas.

1.4. Conceptos fundamentales de ejecución.

- Qué es un intérprete.
- Qué es un compilador.
- Diferencias generales entre lenguajes compilados e interpretados.

1.5. Pensamiento computacional.

- Descomposición de problemas.
- Identificación de pasos.
- Identificación de entradas y resultados.
- Introducción a la lógica de resolución de problemas.

**Resultado esperado:** comprender qué es un programa, cómo funciona y cómo se transforma una solución lógica en instrucciones para un ordenador.

## **Tema 2. Introducción al lenguaje Python**

Conceptual y práctico

Segunda sesión de estudio

**Objetivo:** conocer Python, sus características y sus posibilidades como lenguaje de programación.

**Contenidos:**

2.1. Introducción a Python.

- Historia de Python.
- Origen del lenguaje.
- Características principales.
- Filosofía de Python.
- Sintaxis y legibilidad.
- Diferencias generales con otros lenguajes.

2.2. Aplicaciones de Python.

- Automatización de tareas.
- Desarrollo de aplicaciones.
- Procesamiento de información.
- Creación de herramientas personales.
- Interacción con archivos y sistemas.
- Comunicación con servicios externos.

2.3. Versiones de Python.

- Qué es una versión de Python.
- Versiones principales.
- Diferencias entre versiones.
- Compatibilidad.
- Versiones estables.

2.4. Funcionamiento de Python.

- Qué significa que Python sea interpretado.
- Cómo procesa Python las instrucciones.
- Qué papel desempeña el intérprete.
- Relación entre archivos Python y su ejecución.

**Resultado esperado:** conocer el lenguaje que utilizarás, sus características y los tipos de soluciones que podrás desarrollar con él.

## **Tema 3. Instalación y configuración de Python**

Práctico

Tercera sesión de estudio

**Objetivo:** instalar Python y preparar el ordenador para comenzar a programar.

**Contenidos:**

3.1. Preparación del entorno.

- Requisitos para utilizar Python.
- Descarga de Python.
- Instalación.
- Configuración inicial.
- Comprobación de la instalación.

3.2. Intérprete de Python.

- Qué es el intérprete interactivo.
- Cómo abrirlo.
- Cómo escribir instrucciones directamente.
- Cómo ejecutar instrucciones.
- Cómo salir del intérprete.

3.3. Archivos Python.

- Qué es un archivo `.py`.
- Creación de archivos Python.
- Guardado de programas.
- Ubicación de archivos.
- Diferencia entre ejecutar instrucciones interactivamente y ejecutar archivos.

3.4. Primer programa.

- Creación del primer archivo.
- Escritura de instrucciones.
- Ejecución del programa.
- Visualización de resultados.
- Introducción a `print()`.
- Programa Hello World.

**Resultado esperado:** tener Python correctamente instalado y poder escribir y ejecutar tu primer programa.

## **Tema 4. Herramientas de desarrollo**

Práctico

Cuarta sesión de estudio

**Objetivo:** aprender a utilizar las herramientas necesarias para desarrollar programas de Python.

**Contenidos:**

4.1. Editores de código e IDE.

- Qué es un editor de código.
- Qué es un IDE.
- Diferencias entre ambos.
- Características principales.
- Introducción a Visual Studio Code.

4.2. Visual Studio Code.

- Instalación.
- Configuración inicial.
- Instalación de la extensión de Python.
- Creación de archivos.
- Escritura de código.
- Ejecución de programas.
- Terminal integrada.

4.3. Organización de proyectos.

- Qué es un proyecto de programación.
- Creación de carpetas.
- Organización de archivos.
- Estructura básica de un proyecto.
- Guardado y ubicación de programas.

4.4. Terminal y línea de comandos.

- Qué es una terminal.
- Qué es una línea de comandos.
- Diferencias entre interfaz gráfica y terminal.
- Navegación entre carpetas.
- Ejecución de comandos.
- Ejecución de archivos Python desde la terminal.

**Resultado esperado:** poder utilizar un editor de código, organizar proyectos y ejecutar programas desde la terminal.

## **Tema 5. Gestión básica del entorno Python**

Práctico

Quinta sesión de estudio

**Objetivo:** conocer los mecanismos básicos para ampliar Python mediante paquetes y mantener organizadas las dependencias de los proyectos.

**Contenidos:**

5.1. Paquetes y bibliotecas.

- Qué es una biblioteca.
- Qué es un paquete.
- Diferencias entre módulos, paquetes y bibliotecas.
- Qué son las dependencias.
- Biblioteca estándar y bibliotecas externas.

5.2. Gestor de paquetes pip.

- Qué es pip.
- Para qué sirve.
- Instalación de paquetes.
- Consulta de paquetes instalados.
- Actualización de paquetes.
- Desinstalación de paquetes.

5.3. Entornos virtuales.

- Qué es un entorno virtual.
- Para qué sirve.
- Por qué utilizar entornos independientes.
- Creación de entornos virtuales con `venv`.
- Activación.
- Desactivación.
- Relación entre entornos virtuales y proyectos.

5.4. Preparación de proyectos.

- Creación de un proyecto.
- Configuración de su entorno virtual.
- Instalación de dependencias.
- Organización básica del proyecto.
- Comprobación de funcionamiento.

**Resultado esperado:** poder preparar un proyecto Python con sus propias dependencias y un entorno independiente.

# **2. Resumen de la nueva organización**

## **Módulo 1 · Ruta de estudio**

1. **Tema 1. Fundamentos de programación**

   Comprender qué es programar.
2. **Tema 2. Introducción al lenguaje Python**

   Conocer el lenguaje y sus posibilidades.
3. **Tema 3. Instalación y configuración de Python**

   Preparar Python y ejecutar el primer programa.
4. **Tema 4. Herramientas de desarrollo**

   Aprender a utilizar VS Code y la terminal.
5. **Tema 5. Gestión básica del entorno Python**

   Aprender a gestionar paquetes y entornos virtuales.

# **3. Orden y criterio para estudiar**

Mi recomendación es estudiar los temas en este orden, sin mezclarlos inicialmente.

| Tema                     | Dificultad | Tiempo orientativo |
| ------------------------ | ---------- | ------------------ |
| 1. Fundamentos           | Baja       | 1–2 horas          |
| 2. Introducción a Python | Baja       | 1–2 horas          |
| 3. Instalación           | Baja       | 1–2 horas          |
| 4. Herramientas          | Baja-media | 2–3 horas          |
| 5. Gestión del entorno   | Media      | 2–3 horas          |

Los tiempos son orientativos y contemplan comprensión y práctica inicial.
