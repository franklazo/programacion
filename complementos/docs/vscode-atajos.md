# Atajos de teclado

(*) Combinaciones personalizadas

| Combinación         | Descripción                             |
| :---                | :---                                    |
| `Alt + Click`       | Multicursor: Insertar                   |
| `Ctrl + ↑/↓`        | Multicursor: Insertar arriba/abajo (*)  |
| `Ctrl + L`          | Selección: Línea                        |
| `Ctrl + A`          | Selección: Texto                        |
| `Ctrl + D`          | Selección: Siguiente coincidencia       |
| `Ctrl + Shift + L`  | Selección: Todas las coincidencias      |
| `Shift + Alt + ←/→` | Selección: Expandir/contraer            |
| `Alt + ↑/↓`         | Edición: Mover línea arriba/abajo       |
| `Shift + Alt + ↑/↓` | Edición: Copiar línea arriba/abajo      |
| `Ctrl + C`          | Edición: Copiar línea (selección vacía) |
| `Ctrl + X`          | Edición: Cortar línea (selección vacía) |
| `Ctrl + Shift + K`  | Edición: Borrar línea                   |
| `Ctrl + Space`      | Edición: Activar sugerencia             |
| `Ctrl + Ç`          | Edición: Alternar comentario de línea   |
| `Alt + Z`           | Edición: Alternar ajuste de línea       |
| `Insert`            | Edición: Alternar sobrescritura         |
| `F2`                | Edición: Renombrar símbolo              |
| `Shift + Alt + L`   | Transformación: Minúscula (*)           |
| `Shift + Alt + U`   | Transformación: Mayúscula (*)           |
| `Shift + Alt + T`   | Transformación: Capitalizado (*)        |
