# Restauración

Restaurar configuración del usuario: `User Settings (JSON)`

```json
{
}
```

Restaurar configuración general:

1. Datos sincronizados: `Manage` → `Settings Sync` → `Turn Off` (opcional)
1. Desinstalar Visual Studio Code antes de borrar (opcional)
1. Borrar carpeta `Code` (datos de usuario)
1. Borrar carpeta `.vscode` (extensiones)

```text
%APPDATA%\Code
```

```text
%USERPROFILE%\.vscode
```
