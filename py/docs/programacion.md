# ¿Qué es la programación?

La programación es el proceso de crear instrucciones que una computadora puede ejecutar para realizar determinadas tareas.

Estas instrucciones permiten indicarle al ordenador qué debe hacer, cómo debe hacerlo y en qué orden.

Por ejemplo, podemos crear un programa para:

- Realizar operaciones matemáticas.
- Organizar archivos.
- Administrar una lista de tareas.
- Registrar gastos.
- Automatizar actividades repetitivas.

En esencia, programar consiste en utilizar instrucciones para conseguir que una computadora resuelva problemas o realice tareas.
