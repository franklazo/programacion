# ¿Qué es un lenguaje de programación?

Es un lenguaje formal que permite expresar instrucciones que una computadora puede ejecutar mediante los mecanismos correspondientes.

Los lenguajes de programación tienen:

- **Sintaxis:** reglas que determinan cómo escribir correctamente las instrucciones.
- **Semántica:** significado de las instrucciones.
- **Estructuras:** mecanismos para organizar y controlar el comportamiento de un programa.

Algunos ejemplos son:

- Python.
- Java.
- C.
- C++.
- JavaScript.
- C#.

Cada lenguaje tiene características y aplicaciones particulares.
